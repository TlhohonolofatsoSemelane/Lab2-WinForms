# Lab 2 - Windows Forms (C#)

Windows Forms version of the bicycle rental and mushroom programs from Lab 1.

Flow: Login -> Choose (Bicycle or Mushroom) -> program form -> Logout (back to Login)

- Login: any username, password 1234
- Bicycle: enter the start hour and end hour, the total is shown in a textbox and a message box
- Mushroom: answer yes or no questions (at most 3) to find the mushroom

How to run: open Lab2.csproj in Visual Studio and press F5.
